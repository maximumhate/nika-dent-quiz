# NIKA DENT Quiz

Интерактивная викторина «Какой Вы стоматолог будущего?» для 9 направлений стоматологии.

## Запуск

```bash
npm install
npm run dev
```

Источник вопросов — `quiz-source.md` (копия `Викторина.md`). Команда `npm run build` автоматически собирает из него все 9 веток по 10 вопросов.

## Google Таблица

Результат каждого прохождения отправляется на `POST /api/quiz-results`. Сервер сохраняет направление, сумму баллов, итог и ответы на все 10 вопросов.

Для создания новой таблицы локально положите сервисный ключ в `credentials.json` и выполните:

```bash
npm run sheets:create
```

Передайте ID существующей таблицы через `GOOGLE_SHEET_ID` или `SHEETS_ID` и поделитесь таблицей с email сервисного аккаунта из `credentials.json`. Сервисный ключ и `credentials.json` в репозиторий не входят.

## Production

Приложение собирается в статические файлы и запускается через nginx:

```bash
docker build -t nika-dent-quiz .
docker run --rm -p 8080:80 nika-dent-quiz
```

В production используется `docker compose`: веб-контейнер и отдельный API-контейнер получают Google-настройки из env.
